# 企微伴侣（WeComCompanion）

Windows 桌面应用（pywebview + Python），面向企业微信场景的 AI 工作伴侣：
月报/财务批审自动化、学习中心、自我修复体检、多模型 LLM、工作台、知识库等。

## 快速开始

**下载即用**：从 [Releases](https://github.com/suibuzhifanhua/WeComCompanion/releases) 下载
`WeComCompanion-vX.Y.Z-win64.zip`，解压后直接运行 `WeComCompanion.exe`，无需安装。
首次运行自动生成默认配置与产物库目录。

**从源码运行**：Python 环境 `pip install -r requirements.txt` 后 `python backend.py`
启动（弹出 GUI 窗口，后端监听 8787 端口）。

## 功能亮点

- **月报/财务批审自动化**：分支机构月报批量处理、Excel 交叉校验、断点续跑、后台队列
- **学习中心**：课件采集、考试助手（断点续考、提分策略）、无人值守跑课
- **自我修复体检**：LLM 体检 + 白名单自动修复 + 每日守护
- **多模型 LLM**：本地 Ollama / OpenAI 兼容接口，流式输出 + 判断大模型兜底切换
- **工作台 / 知识库 / 任务宏 / 语音转写 / 智能体团队 / 三工作模式 / 三档权限审批**

## 功能总览

| 模块 | 说明 |
|---|---|
| 工作台 | 企微实时窗口列表 + 截图预览 + 可操作元素 + Agent 聊天；三工作模式（🤖 直接干 / 📋 先出方案 / 💬 只问答）；三档权限级别（🔒 每次询问 / 🛡 自动审批 / ⚡ 完全访问）；👥 智能体团队开关；多任务并行 + 每任务独立模型 |
| 助手对话 | 不绑定窗口的通用对话；未启动企微也能对话并操控电脑 |
| 学习中心 | 无人值守逐门完成学习平台课程（视频/文档/考试自动提分），断点续跑 |
| 模型管理 | 多模型配置（OpenAI 兼容 + Ollama 原生），默认/启用/双模型分工/Token 统计/一键跑分/本地模型扫描/多模型自动兜底 |
| 模板 | 结构化输出模板 + AI 生成模板 |
| 技能中心 | 内置技能 + 公共技能库 + 自定义技能 + 技能版本历史与一键回滚 + 总闸 |
| 连接器 | 通用 HTTP 连接器（配置后 Agent 可调外部 API）+ 功能管理总闸 |
| 自我修复 | LLM 体检：错误日志 + 经验库 → 结构化发现 → 白名单自动修复，代码/配置类只出报告；实时进度、随时取消、每日自动体检、失败自动换备用模型 |
| 版本管理 | 软件内版本库：保留最近 3 个版本，设置页一键切换回退 |
| 产物库 | Agent 产出统一存放（对话记录/下载/产出/技能/上传/知识库/记忆/日志等） |
| 经验库 | 模块 → 问题 → 解决方法沉淀，可增删改查 |
| 知识库 | 课件/题库/制度三分类归档 + 空闲自动整理 + AI 消化 + 企微聊天文件分析（需先在知识库页明确授权，未授权不读取任何文件，可随时撤回）|
| 设置 | 界面偏好 / 功能管理 / 用户固定规则 / 定时任务 / 企微绑定 / 运行组件体检 / 系统信息 |
| 帮助 | 软件内使用速查 |

**内置技能**（均可开关，可从公共技能库一键安装精选技能或自建）：窗口感知、窗口操作、文件产出、企微消息、答题助手、数据下载、数据整理、流程分析、流程总结、财务审核、财务单据核查、报销单填写、联网搜索、会议纪要、文档审阅、周报月报、数据报表分析、公文通知起草、资料调研、待办审批处理、归档整理。

**核心能力**：
- 窗口感知：读取企微窗口正文、列出可交互元素（含必填项检测、同名消歧）
- 窗口操作：点击、输入、选择、滚动、上传文件、编辑在线文档；输入/选择后自动回读验证
- 表单处理：返回必填进度、字段变化与必填标记
- 多格式文件：支持 txt/csv/md/json/pdf/docx/xlsx/pptx 自动解析
- 联网搜索：内置搜索/抓网页
- 专项技能：网页答题（交卷前存疑题列出）、财务单据核查、报销填写（金额一致性校验）、流程分析、流程总结、会议纪要、文档审阅、周报月报、数据报表分析、公文起草、资料调研、待办审批、归档整理
- 脚本优先判定：财务类确定性规则脚本判定（快速、零 LLM 成本），模型兜底
- 经验沉淀：答题规律/审批约定/流程陷阱自动记忆，后续同类任务自动遵循
- 自我修复：每日/手动 LLM 体检 + 白名单自动修复（可回滚）+ 多模型兜底
- 版本管理：每次构建自动登记，一键切换回退
- 技能版本回滚：编辑前自动快照，一键回滚
