          🪞 这是什么（30 秒了解本软件）
          

            
企微伴侣 = 跑在你电脑上的 AI 员工：它通过 CDP 接管企业微信页面，用大模型驱动一套工具链（读页面/点击/输入/传文件/跑命令/写文档），把「学习中心刷课、答题考试、OA 审批、财务单据核查、周报整理」这类重复劳动变成一句话任务。

            
    
              
  • 三层进化体系：经验库（跨任务记忆）→ 技能系统（28 个内置+可安装+自进化）→ 自我修复（体检日志、自动沉淀教训、实验性自动代码修复）；
    • 
              
  • 可靠性地板：死循环熔断、judge 大模型卡点介入、全量回归测试、软件内版本管理（近 3 版一键回退）；
    • 
              
  • 安全边界：删除只进回收站、保护路径/危险命令拦截、密钥 DPAPI 加密、审计留痕；
    • 
              
  • 模型自由：任意 OpenAI 兼容端点 + Ollama 本地；多模型分工（默认模型跑工具循环，卡点自动升级判断大模型）。
    •

          🧭 三工作模式（🤖 直接干 / 📋 先出方案 / 💬 只问答）
          

            
工作台输入框上方有一排模式按钮，当前模式高亮显示。三种模式的具体用法：

            
    
              
  1. 🤖 直接干（默认）—— agent 直接执行：
      
                
    1. 选中左侧一个企微窗口（或不选，纯本机任务）；
      2. 
                
    2. 保持 🤖 直接干 高亮；
      3. 
                
    3. 输入任务（如「把今天的答题数据下载下来」）→ 点 执行；
      4. 
                
    4. agent 开始操作，聊天流里会出现 🔧 工具卡片，随时可点 ⏹ 停止。
      5. 
              
    2. 
              
  2. 📋 先出方案—— 先确认再动手：
      
                
    1. 点 📋 先出方案 切换模式；
      2. 
                
    2. 输入完整任务描述 → 点 发送（状态条会显示「⏳ 模型响应中… Ns」，远端模型首包慢属正常，等待期间可随时点 ⏹ 停止）；
      3. 
                
    3. agent 回复一份方案（目标 / 步骤 / 需补充信息 / 影响面），不执行任何操作；
      4. 
                
    4. 满意 → 点回复底部的 ▶ 按此方案执行，方案自动载入输入框并切回「直接干」，点 执行 开工；不满意 → 直接改需求重新要方案。
      5. 
              
    3. 
              
  3. 💬 只问答—— 只读不写：
      
                
    1. 点 💬 只问答 切换模式；
      2. 
                
    2. 问任何需要读页面/读文件的问题（如「这个页面表单还缺哪几个必填项」）；
      3. 
                
    3. agent 只读取分析、用 Markdown 回答；所有写类操作（点击/输入/写文件/跑命令）都会被拦截并提示。
      4. 
              
    4. 
            

            
💡 模式只对当次发送生效，可随时切换；「先出方案」等待期间想改主意，点 ⏹ 停止即可（1 秒内生效）。配合 👥 智能体团队可叠加使用。

          

        


        

          🗂 多任务并行与模型选择（每任务独立）
          

            
    
              
  1. 同时跑多个任务：工作台发任务 A 后不用等——点左侧任务区 ＋ 新建并发任务 B；运行中的会话标 ⏳ 运行中，点条目随时切换查看实时输出，后台任务不受影响；
    2. 
              
  2. 每任务选模型：输入框下方 模型下拉——任务 A 选本地小模型跑批、任务 B 选远端大模型出方案；选择按会话记忆（下次打开该对话仍生效），「默认模型」= 模型管理页设的全局默认；
    3. 
              
  3. 停止/继续：停止按钮只作用于当前查看的会话；「继续」恢复断点时会保持该会话自己的模式与模型；
    4. 
              
  4. 助手对话页同样有独立模型下拉，且与工作台任务互不干扰——两边可同时各跑一个。
    5. 
            

            
⚠️ 多任务同时用同一个模型服务时，请留意其并发能力（单槽 vLLM 会排队）——给重任务分配不同端点/模型才能真提速。

          

        


        

          📚 知识库自动维护（整理 / 消化）
          

            
    
              
  1. 自动维护（默认开）：软件空闲 10 分钟后，后台自动 ① 重建知识库索引 INDEX.md（含查重告警）② 用 AI 消化最近 24h 新增的文件生成《每日消化》。你在跑任务时它绝不插手；
    2. 
              
  2. 手动整理：点 🧹 立即整理 → 状态条变「⏳ 正在整理…（已 Ns）」→ 完成弹通知。几秒即完，产物是 知识库/INDEX.md；
    3. 
              
  3. 手动消化：点 📖 立即消化 → 「⏳ 正在消化…（LLM 生成中）」约 1-2 分钟 → 完成后《消化_今日.md》出现在 知识库/消化/；
    4. 
              
  4. 没执行的原因：自动消化需要 ① 空闲 10 分钟+ ② 最近 24h 有新增文件。两个条件都不满足时状态条会显示「今日无需消化（24h 无新增）」；LLM 失败当天最多重试 3 次，失败次数会显示在状态里。
    5. 
            

            
💡 企微聊天文件（附件/网盘，静默分析入库）同样参与整理与消化；消化过的内容 agent 都能检索引用。

          

        


        

          💬 企微聊天文件静默分析（自动建知识库）
          

            
软件会静默读取企微的明文文件存储，把聊天里收发的文档自动变成 agent 可检索的知识：

            
    
              
  1. 默认自动：启动 2 分钟后首次扫描，之后每 6 小时增量一次（只解析新增/变更，不重复消耗）；
    2. 
              
  2. 来源：聊天附件（Cache/File/）+ 企业网盘（WeDrive/）中的 pdf/docx/xls/ppt/txt/md 等文档；
    3.

          🎯 持续答题（无人值守）——怎么用
          

            
适用于剩余考试次数 = 无限的学习平台考试。软件会自动：答题 → 交卷 → 读分 → 未过线自动「再考一次」试错，直到及格为止。

            
三种启动方式（都不需要手动输入任何代码）：

            
    
              
  1. 一键入口（推荐）：左侧窗口列表选中考试页面 → 侧栏顶端「⚡ 快捷入口」（默认折叠，点行尾 ▾ 展开）里点「🎯 持续答题」（行尾带「即发」标签）→ 自动开始，无需再点执行；
    2. 
              
  2. 自定义快捷入口：快捷入口编辑器里勾选「即发」（该入口在「⚡ 快捷入口」里带「即发」标签、点击直接执行）和「续跑」（启用自动续跑）——自己输入的任意考试任务也能自动续跑。
    3. 
            

            
自动续跑机制：

            
    
              
  • 每轮考试结束（finish）时，若未达及格分 → 软件自动开全新会话继续下一轮，最多自动续跑 6 次；
    • 
              
  • 每轮答案与归因都记录在产物库 产物库/知识库/题库/答题记录_<考试名>_<日期>.md，新会话靠它接续状态；
    • 
              
  • 及格即停；需要人工确认、出现异常或你点了停止时也会停。
    • 
            

            
⚠️ 无限次数考试才建议用无人值守；剩余次数有限的考试请用「📝 网页答题/填表」入口，存疑题会先问你。

          

        


        

          🎓 学习中心（无人值守）——怎么用
          

            
在学习中心自动逐门完成全部未学课程：学习地图 → 进课程 → 按任务类型处理 → 领证书 → 回地图下一门，直到全部学完。

            
    
              
  • 启动：企微里打开学习中心页面 → 左侧窗口列表选中它 → 点导航顶端「⚡ 快捷入口」里的「🎓 学习中心」→ 自动开跑；
    • 
              
  • 任务类型自动判定：视频 → 自动拖到结尾播完；文档 → 点「立即学习」即完成；考试 → 自动进入考试详情（读及格分/剩余次数）→「开始考试」→ 无限次数自动试错提分（同持续答题）；
    • 
              
  • 进度记录：每门完成写入 产物库/产出/学习进度_<日期>.md，中断后再次启动会接着未完成的课继续，不会重复；
    • 
              
  • 已学完的课程从「未学习」列表消失；全部学完或列表为空时自动收尾汇报。
    • 
            

            
💡 一次启动只跑「未学习」tab 的课程，已学课程不动。

          

        


        

          🔁 自动续跑机制 & 停止任务
          

            
    
              
  • 自动续跑由「🎯 持续答题」入口或勾选了「续跑」的快捷入口触发（v1.0.308 起聊天栏不再放 🔁 按钮，续跑属于学习任务专用）；
    • 
              
  • 随时点 ⏹ 停止 可中断当前任务（自动续跑链也会停止）；
    • 
              
  • 每轮正常耗时约 3-6 分钟；单轮内连续 10 分钟无输出会自动熔断并提示，可点「继续」或重新发起。
    • 
            

          

        


        

          ⚡ 快捷入口管理
          

            
    
              
  • 左侧栏 ✏️ 编辑 打开编辑器：新增 / 删除 / 排序 / 改提示词；
    • 
              
  • 每个入口可勾选：即发 在「⚡ 快捷入口」里标「即发」、点击直接执行（不再显示在聊天框上方）、续跑 启用自动续跑；
    • 
              
  • 点「🤖 AI 生成」用一句话描述需求，可自动生成一组入口；
    • 
              
  • 归类规则：普通入口（提示词类）显示在聊天框上方标签，点击填入输入框；勾了「即发」的重规则任务收在左侧「⚡ 快捷入口」（导航顶端那一组，默认折叠）里，行尾带「即发」标签，点击直接执行。
    • 
              
  • 输入框上方的快捷标签与左侧栏入口是同一份数据，行为一致。
    • 
            

          

        


        

          📝 答题策略说明（为什么这样答）
          

            
    
              
  • 先查知识库：产物库 知识库/课件/ 目录有对应课件/制度原文时以原文作答（内部考题多出自课件/制度原文）；
    • 
              
  • 历史台账复用：同名考试直接复用 答题记录_*.md 里已锁定/已排除的结论；
    • 
              
  • 单变量试错：无限次数考试每轮只改 1 道存疑题，按分数变化归因（升=锁定、降=排除）；
    • 
              
  • 判断题技巧：绝对化表述（"仅…可""必须"）和权限类说法优先怀疑「错误」；
    • 
              
  • 作答纪律：严禁点纯数字题号跳题；交卷防重复点击；每轮落盘台账。
    • 
            

          

        


        

          🌙 深色模式（设置 → 界面偏好）
          

            
勾选后即时切换深色主题并自动记忆，下次启动直接生效（无需进设置页）。

            
    
              
  • 覆盖主界面、聊天窗格、弹窗、输入框、滚动条；个别第三方嵌入元素可能仍是浅色。
    • 
              
  • 偏好保存在本机浏览器存储（WebView2 持久化），换电脑/清缓存后需重新勾选。
    • 
            

          

        


        

          🛡 管理员模式自启动（开机免 UAC 提权运行）
          

            
设置页有两个自启开关：开机自动启动（普通权限，写注册表）与 🛡 管理员模式自启动（计划任务最高权限）。

            
    
              
  • 管理员自启 = 开机后软件直接以管理员模式运行（系统级命令/保护目录/HKLM 全解锁），日常无需再手动提权。
    • 
              
  • 勾选/取消时会弹 UAC 确认框（创建或删除计划任务需要），点「是」完成。
    • 
              
  • 两个开关互斥：勾管理员自启会自动清理普通注册表自启，反之亦然。
    • 
              
  • 「启动后隐藏主窗口」对两种方式都生效（管理员自启模式下切换隐藏设置也会弹一次 UAC）。
    • 
            

          

        


        

          🪟 托盘与任务栏图标（单图标设计 / 幽灵图标清理）
          

            
软件运行时托盘只有一个图标（tooltip 显示版本号）：

            
    
              
  • 双击托盘图标或右键「打开伴侣」= 还原主窗口；右键「退出」= 完全退出（同时清托盘图标）。
    • 
              
  • 点 X 关闭窗口会弹选择：最小化到托盘（后台常驻）或 退出程序。
    • 
              
  • 若见到两个相同图标：其中一个是历史版本残留的"幽灵图标"（鼠标划过即被系统回收），或重启一次资源管理器即可清空。
    • 
              
  • explorer 崩溃/重启后托盘图标自动重新注册，无需重启软件。
    • 
            

          

        


        

          📦 打包并重启（版本管理卡）
          

            
设置 →「维护 · 版本 · 安全」→ 版本管理卡 →「📦 打包并重启（用当前源码）」：程序 2 秒后退出 → 后台打包 1-2 分钟 → 自动启动新版本。

            
    
              
  • 打包期间对话活动会被保护拦下（稍后再试），软件内一键打包自动跳过该保护。
    • 
              
  • 自我修复成功提交代码后，报告会提醒"修复已写源码，需到版本管理打包才生效"。
    • 
              
  • 版本自动 +1 并登记进「版本管理」（近 3 版可一键回退）。
    • 
            

          

        


        

          🔍 绑定后状态显示"未连接"？
          

            
    
              
  • 重新绑定成功后，顶部状态条可能有几秒延迟——点「刷新状态」立即更新。
    • 
              
  • 若始终"后端未响应/0 个可访问"：确认企业微信本体正在运行且用带调试参数的方式启动过一次；再到「企微」页看「重新绑定」是否报错。
    • 
              
  • 自动绑定失败（WinError 2）= 配置里没有企微 exe 路径，手动「重新绑定」一次即可。
    • 
            

          

        


        

          ⏱ 关于启动速度（动画期间在做什么）
          

            
加载动画期间软件在做：解压运行环境 → 初始化 Flask 与全部路由 → 启动 WebView2 → 前端轮询 /api/status 确认就绪。实测全程 2-4 秒（服务就绪后动画 1.7 秒内淡出）。

            
    
              
  • 开机后第一次启动慢多为杀毒软件实时扫描解压目录——建议把 %TEMP% 下的 _MEI* 目录与软件 dist 目录加入杀毒白名单。
    • 
              
  • 远程桌面（RustDesk 等）里动画观感会更久，是远程帧率所致，本机实际已就绪。
    • 
              
  • 开启了「开机自启」后软件随系统在后台常驻，日常从托盘打开是秒开。
    • 
            

          

        


        

          ❓ 常见问题
          

            
    
              
  • 点「持续答题」没反应？——先确认左侧已选中企微考试窗口；未选中会提示。
    • 
              
  • 任务停在某轮不动？——看工作台是否显示「需人工继续」，点「继续」；或 ⏹ 停止后重新发起。
    • 
              
  • 成绩和答案在哪看？——产物库 → 知识库/题库 → 答题记录_<考试名>_<日期>.md（含每轮分数轨迹与归因）。
    • 
              
  • 续跑 6 次还没过？——停止续跑并汇报最优分数与仍存疑的题，可人工接管或重新发起。
    • 
              
  • 学习中心遇到"0 题空考试"？——答题页读不到任何题目（只有答题卡/计时）时软件会自动退出跳过并记台账，不影响完成课程（v1.0.262+）。
    • 
              
  • 模型后台显示在请求但我没用它？——任务在启动那一刻用的是当时的默认模型；中途在「模型管理」改默认只对新任务生效。想彻底不用某模型，把它「禁用」或删除即可。
    • 
              
  • 想自定义考试任务？——用「🎯 持续答题」入口或勾了「续跑」的快捷入口直接输入，例如"完成当前考试，及格 80 分"。
    • 
              
  • 程序点了没反应/消失了？——重启 dist\WeComCompanion.exe；日志在 dist\companion.log。
    • 
              
  • 点右上角 × 会退出吗？——默认最小化到托盘（右下角图标），右键托盘图标可选真正退出；单实例运行，重复启动会自动聚焦已有窗口。
    • 
              
  • 「模型管理」里测试/跑分没问题，体检却说模型没返回？——体检 prompt 较大，部分本地/共享模型会空转；v1.0.362 起会自动吃满重试并换备用模型，仍失败时按提示换默认模型或等网络空闲再试。
    •
